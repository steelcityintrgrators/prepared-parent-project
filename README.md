# The Prepared Parent Project

Alabama-focused parent education and resource-navigation system.

## Mission direction
Preparing Alabama parents. Strengthening Alabama families.

## Non-law-firm boundary
The Prepared Parent Project is not a law firm, does not provide legal advice or legal representation, and does not create an attorney-client relationship.

## Product rules
- Legal/court content is educational only.
- Situation-aware navigation: parents are not forced into a one-size-fits-all answer.
- Alabama legal propositions must be supported by applicable Alabama statutes/rules and relevant verified Alabama appellate case law before public publication.
- Missing or unverified authority is a publication stop condition.
- No branding, copy, titles, URLs, or features may state or imply that the project is a law firm.
- High-risk legal content requires human legal/safety review before publication.

## Initial build
This repository is the production codebase for the public website, situation-aware navigator, authority library, resource directory, content verification layer, and future automation.
