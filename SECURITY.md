# Security and Privacy Policy

## Public-repository boundary
This repository contains only public website code, public educational content, and non-sensitive operating documentation.

It must never contain:
- a parent's or child's private case file, court exhibit, school record, medical information, address, phone number, or birth date;
- intake submissions, donor lists, banking data, board-confidential records, credentials, API keys, OAuth tokens, or production `.env` files;
- individualized legal strategy or information represented as legal advice.

The Prepared Parent Project is not a law firm. Legal and court-related content must remain educational, situation-aware, and supported by verified Alabama authority.

## Report a vulnerability
Email **thepreparedparentproject@gmail.com** with the subject `SECURITY REPORT`. Do not disclose exploit details or personal information in a public issue.

## Response
Remove public access to exposed data, preserve audit evidence, rotate affected credentials, document the incident, and notify appropriate professionals or affected people when required.
