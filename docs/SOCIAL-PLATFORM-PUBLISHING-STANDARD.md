# Social Platform Publishing Standard

Updated: 2026-10-22

## Universal
- Build platform-specific outputs; do not assume one presentation mode fits every platform.
- Vertical short-form production master: 1080x1920 (9:16), H.264/AAC MP4.
- Keep critical text, logo, CTA and disclaimers away from interface overlays and edges.
- Never add black bars/padding to vertical YouTube video.
- Use owned/licensed media and verify educational/legal claims before publication.
- Visually inspect rendered frames before publishing.

## Instagram
### Reels / Stories
- Production master: 1080x1920, 9:16.
- Keep key creative elements in a conservative central safe zone because Reels UI overlays the right/bottom.
- Publish vertical video as Reel; share to feed when appropriate.
- Lead with a hook; concise caption; relevant/niche hashtags.
### Feed
- Portrait master: 1080x1350 (4:5); square fallback 1080x1080.
- Do not reuse a 9:16 static design without a feed-specific crop.
### Policy
- Use original/licensed content. Branded/compensated content requires applicable paid-partnership disclosure.

## Facebook
- Meta says Facebook is transitioning video posting into Reels; during the rollout videos can be any length/orientation.
- Preferred mobile vertical creative: 1080x1920, 9:16.
- Use a Facebook-specific publication profile rather than blindly reusing Instagram metadata.
- Keep key messages in safe zones.
- Facebook captions can be more descriptive than Instagram while remaining concise and encouraging useful comments/shares.
- Confirm Public audience for public educational content.
- Visually verify the actual Facebook result because presentation/cropping can differ from Instagram.

## YouTube
### Shorts
- Square or vertical video up to 3 minutes is eligible for Shorts.
- Production master: 1080x1920 (9:16), 1080p.
- Do not add black bars/padding.
- Title maximum: 100 characters.
- Set audience correctly (Made for Kids / Not Made for Kids).
- Shorts custom thumbnails: 9:16.
### Standard video
- Production master: 1920x1080 (16:9).
- Standard video thumbnail: 16:9.
- YouTube's standard desktop player is 16:9.

## Prepared Parent acceptance gates
1. Correct platform dimensions/aspect ratio.
2. H.264/AAC MP4 for video delivery.
3. Text fully inside protected content region.
4. No critical content in right/bottom UI overlay zones.
5. Logo readable/unobstructed.
6. Disclaimer readable where required.
7. No unlicensed media.
8. Copy approved and source URL present when required.
9. Platform-specific metadata selected.
10. Render visually inspected before publication.
11. Live post verified after publication.
12. Failed live presentation triggers a platform-specific correction, not a global change.
